# Casa Amara Image Assets Guide

This folder contains the image placeholders for the Casa Amara Boutique Hotel website. You can easily replace any SVG placeholder with your real photos (JPG, PNG, or WebP).

### Recommended Dimensions & File List

| File Name | Section | Recommended Size | Description |
| :--- | :--- | :--- | :--- |
| `hero-bg.svg` | Hero Section | `1920 x 1080 px` | Main suite interior with balcony / city view |
| `deluxe-room.svg` | Rooms & Suites | `800 x 550 px` | Deluxe Room (sculpted headboard & garden-facing bed) |
| `executive-room.svg` | Rooms & Suites | `800 x 550 px` | Executive Room (terrace, deep soaking tub, daybed) |
| `family-room.svg` | Rooms & Suites | `800 x 550 px` | Family Room (two queen beds, inner courtyard view) |
| `premium-suite.svg` | Rooms & Suites | `800 x 550 px` | Premium Suite (most spacious retreat, separate lounge) |
| `amenities-arch.svg` | Hotel Amenities | `900 x 1000 px` | Whitewashed architectural arches & suite view |
| `dining-table.svg` | Beyond Your Room | `600 x 700 px` | Amara Table restaurant setting |
| `garden-pool.svg` | Beyond Your Room | `600 x 700 px` | The Garden Pool with palm trees and loungers |

### How to Replace:
Simply drop your images into this folder (`assets/images/`) with the same filenames, or update the `src="..."` paths in [index.html](../../index.html).
